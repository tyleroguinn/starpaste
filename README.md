# Starpaste

Tap-to-copy astrology symbols: planets, zodiac signs, aspects, asteroids, points, elements, moon phases and sparkles.

The whole site is one file, `index.html`, hosted with GitHub Pages.

## iPhone keyboard

The `ios/` folder holds a Starpaste iPhone app with a custom keyboard, so you can type the symbols in any app. See [ios/README.md](ios/README.md) for how to put it on your phone.
